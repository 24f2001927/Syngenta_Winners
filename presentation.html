System Design

LangGraph Bayesian Pipeline

A directed state machine with 9 nodes. Four optionally use NVIDIA LLM with automatic fallback to deterministic logic.

Ingestion → NER Extraction ↕ NVIDIA LLM
↓

● LLM Nodes (NVIDIA meta/llama-3.1-8b)

  • NER Extraction — misspellings, regional names, multilingual
  • Suitability Index — biophysical reasoning from weather + pathogen
  • Likelihood — contextual P(Wt | Dactive)
  • Decision — structured prescription: product, dosage, measures

● Graceful Degradation

  • Has API key? → Validate (chat completions probe, 5s)
  • Fail / No key → Deterministic fallback instantly
  • Network error / Timeout (10s) → Fallback
  • Bad response JSON → Fallback
